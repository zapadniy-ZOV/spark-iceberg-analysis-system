# spark-iceberg-analysis-system

Аналитический модуль для проекта `ZOV`, построенный на `PySpark`. Проект читает данные пользователей и регионов из `MongoDB`, обрабатывает их в `Spark`, формирует отчетность по регионам и сохраняет результаты в таблицы `Apache Iceberg` в объектном хранилище.

## Что делает проект

- загружает данные пользователей и регионов из `MongoDB`;
- сопоставляет пользователей с конечными регионами на основе иерархии территорий;
- рассчитывает агрегаты по численности и доле неактивных пользователей;
- формирует аналитический отчет по смертности/потерям по регионам;
- записывает результат в `Apache Iceberg`;
- поддерживает два режима работы: пакетный и потоковый.

## Основные сценарии

### `main.py`

Пакетная аналитика:

- выполняет разовую загрузку данных из `MongoDB`;
- строит итоговый отчет по регионам;
- записывает результат в Iceberg-таблицу.

### `main_streaming.py`

Потоковая аналитика:

- читает изменения пользователей через streaming;
- обрабатывает микробатчи в `Spark Structured Streaming`;
- обновляет Iceberg-таблицу с аналитическими показателями;
- использует checkpoint для устойчивой потоковой обработки.

## Назначение в системе

Этот проект отвечает за аналитический слой экосистемы `ZOV`: берет оперативные данные из основной базы, рассчитывает агрегированные показатели и формирует отдельное аналитическое представление, пригодное для отчетности и дальнейшего анализа.
